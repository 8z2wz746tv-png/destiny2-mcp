# 用中文问自己的命运 2 账号：一个本地 MCP 服务

这是一个跑在你自己电脑上的小服务，按 MCP 协议接进支持 MCP 的 AI 客户端（DSH、Claude Code、Codex 这类）。
接好之后不用点界面，直接用中文提问：我有什么、这把枪什么词条、帮我配一套、这周商人卖什么。
数据全程留在本机，读写都走你自己的 Bungie 授权。下面按八个工具分节说能干什么，每节给几条能直接复制去问的话。

## 一、`player_assistant`：先认识你的角色

看你的角色列表、光等和基本档案；名字记不全时按前缀模糊找人；精确搜到某个玩家后拿到 `membership_id`，后面查别人也用得上。
自己账号不用每次报名，服务默认就查你登录的那个。

可以直接复制：

- 我三个角色现在都多少光等？
- 我名字记不全，帮我找找名字里带「夜」的玩家

## 二、`inventory_assistant`：背包和仓库

数一下背包/仓库有多少东西、按名字或类型列清单、找重复武器、看单件护甲的插槽和能量、移动物品、装备、批量装备、从邮政官取回、锁定解锁、追踪任务。
重复武器按精确的物品 hash 分组，所以是「同名同款」的真重复，不是同名不同版本。
要看单件护甲的插槽、能量、三层属性（`roll`/`base`/`final`）、大师与调谐，用 `intent="item"` 配 `item_instance_id`；
只要清单就别读那么细，列表是轻量的。

可以直接复制：

- 我仓库里有多少把火箭筒？列出来看看
- 帮我找找有没有重复的「痛苦的饥饿」
- 把仓库里那把「遗产」装到我的猎人身上

（上面最后一条会改账号状态，服务会先给你一份确认清单。）

## 三、`weapon_assistant`：武器和词条

分清两件事：**我这把现在是什么**（`filter_rolls`、`analyze`、`compare`）和**这把枪能滚出什么**（`perk_pool`）。
另外还能查：全游戏有哪些枪能滚出某个 perk（`catalog`）、某个 perk 到底什么效果（`perk_description`）、
社区愿单里的 god roll（`god_roll`）、大家一般选哪个 perk（`popularity`），以及本地社区武器资料（`community`）。
`catalog` 查的是游戏里的定义，不代表你拥有；要问「我有没有」，得走 `filter_rolls`。

可以直接复制：

- 我这把「遗产」现在是什么词条？留哪把比较好？
- 我仓库里有没有带「萤火虫」的手炮？
- 「高爆载荷」这个 perk 具体是什么效果？

## 四、`build_assistant`：配装和刷取目标

按你给的目标求解一套配装：指定职业、金装，给六维目标（武器/生命值/职业/手雷/近战/超能），
它从你的库存里挑护甲和模组。配不出来时会告诉你差在哪、放松哪一项就能出解（`analyze`），
还能反推「该去刷哪一件护甲」（`farm_target`）。
另外有护甲模组列表（`armor_mods`）、异域护甲和套装效果（`exotic_armor`、`set_bonus`），
以及社区配装模板搜索（`community`）——社区模板是给人看的方案，不能一键执行。

可以直接复制：

- 帮我配一套术士烈日手雷流，手雷 100 生命 100
- 术士带「星火协议」，手雷 100 超能 100 能配出来吗？配不出来差多少？
- 我想换一件胸甲，刷哪件最合适？

## 五、`loadout_assistant`：我自己存过的配装

列出你存过的配装和 Bungie 官方配装槽、保存当前这一套、换上一套已存的、删除，
还能搜官方槽位的名称/图标/颜色标识，把官方槽位存成快照或清空。
注意这里只有**你自己存过的**配装；网上的社区配装走 `build_assistant` 的 `community`，两边不是一回事。

可以直接复制：

- 我存过哪些配装？都列出来
- 帮我换上一套叫「宗师奶枪」的配装

## 六、`subclass_assistant`：子职业、碎片和神器

看当前超能、手雷、近战、星相、碎片；查某个元素下有哪些技能可选（`options`）、碎片列表和单个碎片效果
（`fragments`、`fragment_details`）；看赛季神器和神器模组（`artifact`、`artifact_mod`）。
改技能用 `modify`，装神器模组用 `equip_artifact_mod`，换神器用 `equip_artifact`，这些都是写入，会先要一次确认。
元素中文名认：虚空、烈日、电弧、冰影、缚丝、棱镜。

可以直接复制：

- 我现在术士带的什么超能和碎片？
- 烈日术士有哪些手雷可以选？
- 「仁慈余烬」这个碎片什么效果？

## 七、`activity_assistant`：战绩

看最近几场活动（`history`）、单场结算详情（`pgcr`）、生涯统计（`stats`）、游戏内计数器（`counters`）、
武器使用排行（`weapon_history`）、按活动类型聚合（`aggregate`）、自己在榜单上的位置（`leaderboards`）
和公会排行榜（`clan_leaderboards`，需要公会 ID）。问「最近几场」就走 `history`，
只有问某一场的具体结算才需要活动 ID。

生涯数字有两个来源，**都对但不一样**：游戏内计数器（`counters`，`profile.metrics`，从第 1 赛季起累计、
含已删角色）是游戏里显示的那个数；统计接口（`stats`，默认账号级，每行给「现存角色 / 已删角色 / 账号合计」
三档，账号合计已包含已删角色）是 Bungie 后端的明细，还有 K/D、胜率、按模式（`mode=trials`）这些。
两个数不要相加。`stats` 的 `period` 只认 `career`：**统计接口没有赛季周期**，赛季数字只能问 `counters`。

可以直接复制：

- 我最近 10 场突袭打得怎么样？
- 我生涯一共打了多少场 PvP？最常用哪把枪？
- 我试炼打得怎么样？（`stats` + `mode="trials"`）
- 我这赛季熔炉击败了多少？（`counters` + `period="season"`）

## 八、`world_assistant`：周常、商人和收藏品

看本周有什么活动（`weekly`，`weekly_full` 更全）、商人本次**实际在卖**什么（`vendor`，含商品这一份的真实 perk，
不是这把枪的总 perk 池）、收藏品节点和某件物品的解锁状态（`search_collectible_nodes`、`collectible_node`、`collectible_item`）。
社区机制和获取途径资料也在这里查（`community`），而且它是唯一能跨分类搜的入口。

可以直接复制：

- 这周有什么周常活动？
- 班西-44 现在在卖什么？有什么值得换的？
- 帮我看看「苍白之心」的收藏品我解锁到哪了

## 0.3.0 新加的两个能力 🆕

### 换子职业

以前只能在**当前**子职业上改插槽，想从棱镜切烈日是切不过去的。现在 `subclass_assistant(intent="modify")`
多了一个变更键 `changes`，可以整套换：

    changes={"subclass": "烈日"}

也认口语叫法：「火术」「棱镜术士」「solar」都行；Manifest 里的官方子职业名（破晓、枪手、炎阳这类）也认。
已经是目标子职业就不写；找不到会把这个角色实际有的子职业列给你；
职业叫法对不上（比如猎人说「火术」）会直接报错，不会硬切。

可以直接复制：

- 把我的术士换成火术
- 我这套猎人想切成虚空，换完顺便看看碎片

### 换神器

`subclass_assistant(intent="equip_artifact")` 用 `artifact_name` 指定官方神器名，
把这个角色背包里的另一件神器换上。查询时带上 `character`，`intent="artifact"` 会顺带告诉你
他身上那件和背包里能换的有哪些——目录里的「当前神器」是按赛季算的，跟身上那件可以不一样。

可以直接复制：

- 我的术士现在带的是哪件神器？背包里还有能换的吗？
- 把术士背包里那件「好奇之器」换上

## 使用前要知道的边界

1. **社区资料是本地快照，不是实时数据。** 随包的社区配装、武器推荐、Perk 和 DPS 资料来自 **Starside**
   （<https://starside.work/index.html>），经网站作者许可随附与再分发。它是参考数据，不是 Bungie 官方数据，
   也不保证适用于当前游戏版本；每条引用都保留了来源和更新时间，出处与授权边界见
   `docs/community/COMMUNITY_DATA_NOTICE.md`。社区评分不等于官方推荐。
2. **三档来源不能混。** Manifest 定义 = 游戏里有什么；你的账号 = 你实际有什么、装的是什么；社区资料 = 别人怎么说。
   拿定义级结果说「你有/你没有」是错的；社区资料也不能当官方事实用。口诀是：账号=我有什么，Manifest=游戏里有什么，社区=别人怎么说。
   三档数据都落在本机，首次运行要下载并建库约 717 MB 的 Manifest，这期间服务不响应，属于正常现象。
3. **改账号的操作会先要一次确认。** 装备、换模组、换神器、换子职业、移动物品这些写入，
   服务会先把精确目标（哪一件、哪个槽、从什么换成什么、数值怎么变）摆出来等你点头，写完再回读核对。
   你说「不用问直接执行」也不行，确认必须来自你自己。
4. **神器不能跨角色转移。** 神器在游戏里就不可转移，所以只能换**同一个角色背包里**的那一件；
   想给别的角色换，得先在游戏里把它弄过去。
5. **上游有同步延迟。** Bungie 那边写完不一定立刻读得到，刚改完马上查可能还是旧值。
   服务会在十几秒的窗口内反复回读，超过窗口还读不到就如实说「没确认」——那不代表没改成，只是没读到。
6. 另外两条实测限制：花能量的插槽写入需要在 Bungie 应用里勾选 `AdvancedWriteActions` 权限，没有会明确报权限问题；
   调谐**能换，也能替你换**（2026-09-22 起）—— 条件只有一条：那颗在**这件护甲允许的清单**里
   （每件不一样，读组件 310）。清单外的上游会回 1675，工具会明说"这颗装不到这件上"，不写。

## 怎么装

获取方式：把仓库地址 <https://github.com/8z2wz746tv-png/destiny2-mcp> 交给你的 AI 客户端，让它按 README 走一遍安装流程即可；
需要你**自备一个 Bungie API 应用并完成一次 OAuth 登录**，凭据和 token 只存本机，不要贴进聊天里。

## 常见问法对照

| 你想问的 | 该走哪里 |
| --- | --- |
| 我有没有某把枪 / 某个 perk | 账号侧：`filter_rolls`、`analyze`、`type` |
| 游戏里一共有哪些枪能滚出这个 perk | 定义侧：`catalog` |
| 这把枪**可能**滚到什么 | `perk_pool` |
| 我这把**现在**是什么 | `filter_rolls`、`analyze`、`compare` |
| 这个 perk 什么效果 | `perk_description`（不按名字猜） |
| 别人怎么配 / 怎么打 | 各工具的 `community`，跨分类用 `world_assistant` |
| 我自己存过的配装 | `loadout_assistant(intent="list")` |

不确定的地方就写「具体情况看你的账号」：分级、词条、能不能换，往往逐件副本都不一样。
