# 口语测试语料（人工照着说）

这份是**给自己手测用**的自然语言清单：一句话一个功能，也有一部分一句话拼多个要求。
和 `TESTING_CORPUS.md`（代码行、脚本跑）分工不同 —— 这里测的是"用户随口这么说，工具接不接得住"。

用法：挑一条照着说（或原样粘进对话）。每条后面括号里是**该看什么**，不是要照着念。
写入类的句子会改账号，**只有在你明确说"确认"之后才会执行**；后面带 🔒。

## 一、账号与角色（`player_assistant`）

| # | 照着说 | 该看什么 |
| --- | --- | --- |
| 1 | 我号上有几个角色，都多少光等？ | 三个角色 + 光等；名字是 `你的名字#数字`（不是 Steam 名） |
| 2 | 我术士上次什么时候玩的？ | 最后游玩时间对得上 |
| 3 | 帮我找找叫 husky 的玩家 | 给候选列表（名字记不全时用模糊搜） |
| 4 | 查一下 OneTop丶Husky#6641 | 精确搜，给 membership_id |

## 二、背包与仓库（`inventory_assistant`）

| # | 照着说 | 该看什么 |
| --- | --- | --- |
| 5 | 我仓库里有多少东西？ | 数量概况（不是把 1000 件全倒出来） |
| 6 | 我手炮都有哪些？ | 按类型列（默认 20 件 + 总数/是否截断） |
| 7 | 帮我找「无感」 | 按名字找，给实例 ID |
| 8 | 我有哪些重复的武器？ | 按 item_hash 分组，能核对是同款不同副本 |
| 9 | 🔒 把仓库里那把「无感」挪到术士身上 | 先给计划 + 要确认；确认后回读核对位置 |

## 三、武器（`weapon_assistant`）

| # | 照着说 | 该看什么 |
| --- | --- | --- |
| 10 | 「玉兔」能出哪些 perk？ | Perk 池按栏位分组 |
| 11 | 我手里的手炮有没有带「测距仪」的？ | 只查**你持有**的副本（`scope=owned_inventory`） |
| 12 | 全游戏哪些手炮能出「爆破专家」？ | 查 Manifest 全量（`scope=manifest_catalog`），不限你有没有 |
| 13 | 「鹰月」这把枪怎么样？ | 属性 + 框架评价；不吹不黑 |
| 14 | 大家用「鹰月」都选什么 perk？ | 选取率；标明是社区统计，不是推荐 |
| 15 | 「测距仪」这个 perk 什么效果？ | Perk 文本 |
| 16 | 我这把「坏疽」和仓库那把比一下 | 逐项差异，不是各说一遍 |
| 17 | 「无感」是 T 几？ | 分级；不在分级体系里要说 null 而不是 T0 |
| 17b | 我的锻造图样还差哪几把？ | `patterns`：183 条图鉴里的进度（进行中排前面）；`未开始` 说成"账号里没有这条记录"，不许说成 0/5 |
| 17c | 「累积救赎」的图样还差几次？ | 单把：进行中 4/5 → "还差 1 次深视萃取"，并给掉落来源（社区资料，带更新时间） |
| 17d | 「惩戒措施（失时）」的图样呢？ | 变体没有单独图样，指回基础版「惩戒措施」，并说明这条口径 |

## 七、战绩（`activity_assistant`）

| # | 照着说 | 该看什么 |
| --- | --- | --- |
| 33 | 我最近打了什么？ | 最近活动列表（默认 20 条） |
| 34 | 我最近那场突袭的详细结算给我看看 | 先拿 history 的实例 ID，再给 6 人结算；参与者名是游戏内 ID |
| 35 | 我熔炉生涯一共击败多少？ | 账号级三档（现存/已删/账号合计），并说明统计接口口径 |
| 36 | 我游戏里显示的熔炉击杀是多少？ | 走游戏内计数器，数字与 35 可能不同 —— **两个都给、别相加** |
| 37 | 我试炼生涯打了多少胜、击败多少？ | 试炼 10696 / 胜场 826（生涯） |
| 38 | 我铁旗本赛季杀了多少？ | 铁旗 + 本赛季（计数器） |
| 39 | 本赛季 PvP 击杀了多少？ | 只有计数器能答；统计接口没有赛季 → 要如实说 |
| 40 | 最近 10 场 PvP 我主要用什么枪？ | `pvp_weapons`：**必须带时间窗**，说清是"最近 N 场"不是生涯 |

| 42 | 我最近打的 PvP 都是什么模式？ | 模式名是官方中文（如「铁旗占领模式」），不是"模式43" |
| 43 | 我在排行榜上排第几？ | 上游返回空时要**如实说**，不许编排名 |

| # | 照着说 | 该看什么 |
| --- | --- | --- |
| 49 | 我术士现在穿的什么？离 180 手雷还差多少？ | 先读装备再算差值，一个答案里说完 |

## 十、必须"拒绝"的句子（测不编、不猜、不硬来）

| # | 照着说 | 期望的结果 |
| --- | --- | --- |
| 56 | 我「猛攻」打了多少场？ | 报错并列出可用模式词（"猛攻"不在词表里） |
| 57 | 我上赛季的 PvP 击杀是多少？ | 说清只有生涯/本赛季；拿不到就说拿不到 |
| 58 | 我生涯的 PvP 武器榜 | 给最近 N 场 + 说明上游没有生涯口径，**不许当成生涯** |
| 59 | 帮我把那把枪装上 | 缺实例 ID → 报错让你先查，不许猜一件 |
| 60 | 我熔炉的胜率是多少？ | 能算就给公式，算不出给 null，**不许编** |

## 十一、写入确认流程（🔒 会真的改账号，都可逆）

1. 先说一句写入类的话（如 9 / 26 / 31 / 32），**不给确认** → 应该只给计划 + `confirmation_required`。
2. 再说"确认" → 执行，并在 3～10 秒的同步窗口内**回读核对**；核对不上要报 `unverified`，不许报成功。
3. 护甲模组那条是**故意的例外**：可以说"帮我把术士头盔模组换成加手雷的"，预期是**如实报权限不足、让你在游戏里装** —— 这不是 bug（见 ADR-002）。

## 怎么判断这一轮算过

- **数字类**：同一个数在不同 intent 里应该各自带口径标签（生涯/本赛季、账号级/单角色、窗口/全模式），不该出现两个数悄悄混用。
- **失败类**：`ok=false` + 一句中文说明"缺什么/下一步"，不是裸报错、不是空列表。
- **写入类**：没有你的明确确认就不许落盘；落盘后必须回读。
- **口径陷阱**（35/36、39/40、44、58）：工具要主动说清"这是哪个口径"，而不是等你追问。
